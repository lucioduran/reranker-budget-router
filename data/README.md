# Dataset provenance

The corpus and queries are unchanged MIT-licensed fixtures from
https://github.com/lucioduran/rag-evaluation-workbench at commit `60246831be5cf68768710e83d7b41614e49a8341` (project 02).
They contain 24 fictional station-operation documents, 12 development queries,
and 26 evaluation queries, including two evaluation queries without relevant documents.
Source-document groups are disjoint across splits. Queries within a group are correlated.
This is an authored toy corpus, not a representative retrieval benchmark.
No private data or human assessment was collected. The upstream MIT license is preserved
in the repository LICENSE. Evaluation labels are used only after the policy is frozen.
