# Security

This project runs local inference and reads JSON files. Do not treat the verifier as
proof of measurement authenticity. Hashes detect changes relative to a manifest, not
a malicious publisher who replaces all evidence. Only download trusted pinned model
revisions. Remote model code is disabled and safetensors weights are required.
Report defects through the repository issue tracker without posting secrets.
No security audit or production-hardening claim is made.
